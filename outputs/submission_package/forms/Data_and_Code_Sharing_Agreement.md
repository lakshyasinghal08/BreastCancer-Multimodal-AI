DATA AND CODE SHARING AGREEMENT
Manuscript Title: "A Unified Seven-Modality Cross-Attention Transformer for Clinically Robust, Uncertainty-Aware Breast Cancer Diagnosis and Molecular Phenotyping"

The authors agree to the following data and software sharing terms upon publication:
• Public Datasets: Complete accession links and harmonization pipelines provided in Section 2 and Supplementary Material.
• Source Code: Complete codebase released under open-source Apache 2.0 license on GitHub.
• Long-Term Preservation: Zenodo DOI repository created with immutable digital object identifier.
• Pretrained Checkpoints: Frozen expert encoders and multimodal fusion weights deposited in public model registry.
